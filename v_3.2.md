New features:

  🤖 Separate AI Endpoints:
     Chat and Embedding now have independent config:
     CHAT_API_URL / CHAT_API_KEY / CHAT_MODEL / CHAT_API_TYPE
     EMBED_API_URL / EMBED_API_KEY / EMBED_MODEL / EMBED_API_TYPE
     Set api_type to 'openai' for OpenAI/vLLM/LiteLLM/etc.
     Defaults to Ollama (backwards compatible).

  🦆 Logo links to Dashboard (click duck or 'QuackBox')

  ⚡ Realtime search — results update as you type (350ms debounce)
     No more clicking 'Search' button.

  📌 Sidebar navigation — collapsible, persists state, sticky.
     Click collapse arrow or use on narrow screens.

  🏷️  Version v3.2

  To use OpenAI instead of Ollama, edit docker-compose.yml:
    CHAT_API_URL=https://api.openai.com
    CHAT_API_KEY=sk-...
    CHAT_MODEL=gpt-4o-mini
    CHAT_API_TYPE=openai
