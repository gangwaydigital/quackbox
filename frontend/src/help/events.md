# Events

Events lists the meeting invites and `.ics` calendar files hiding in your mail, with time, place, organizer and attendees.

## Before you start

The page is empty until you click **Index events**. It scans every imported email for invites and calendar attachments. After a later import, click **Re-index** to pick up new ones. A green message reports how many events were found.

## Controls

- **Upcoming / All** switch. Upcoming shows events that have not started yet. Choose **All** to see past events, which are shown slightly faded.
- **Search** box: matches summary, location and organizer.
- **Index events / Re-index**.
- On each card: the title, a status tag (confirmed, tentative or cancelled), the time range, location, organizer, attendees (names are listed when there are four or fewer) and the start of the description. The small arrow icon opens the email the event came from.

![Events list with upcoming and all filters](/help/events.png)

## Example

To find where last year's team offsite was held: click **All**, search for `offsite`, and read the location line on the card. Open the email for the full invite.

> **Tip:** Most mail archives are old, so if **Upcoming** looks empty, that is normal. Switch to **All**.
